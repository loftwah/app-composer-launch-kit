Your artwork,
on your device.

Choose a PNG, JPEG or still WebP up to 10 MiB, 16 megapixels and 8192 pixels per side. Files are checked by format bytes and native decoding; extensions are not trusted. SVG, animated WebP and ICO are outside this version.

Make the small version work

Inspect the 16px preview at its actual size. A busy drawing can become unreadable. Try fill and crop, adjust the focus, reduce breathing room or choose simpler artwork. Warnings are guidance, not an aesthetic score.

Adaptive icons

Maskable outputs always use a solid background and separately contain the whole artwork inside the central safe circle. Phone touch icons also use a solid background. Ordinary icons can preserve transparency.

Keep and reuse your work

The ZIP contains nine PNGs, a web manifest, HTML markup, launch-kit.json and instructions. Original source bytes are excluded. Reopen the configuration and explicitly choose the matching source image to regenerate it. Output PNG bytes can differ between browser engines or versions.

Privacy

Image decoding, rendering, hashes and ZIP packaging run locally. No upload endpoint, analytics or remote codec is used. The sample and fonts are same-origin static assets. Theme preference alone is saved locally. Your source image, filename, EXIF and text are not added to URLs or network requests. Ordinary hosting access logs still apply to page requests. Composer adoption requires an explicit local file selection and review.

Accessibility

File selection works with keyboard and touch. Every range control has a label and supports arrow keys. Tab reaches all controls; focus stays visible in both themes. Reduced motion is respected. Layout reflows on phones and when zoomed. Physical iOS, screen-reader and native sharing acceptance remain separate from browser automation.

Installation and sharing

Review manifest name, paths, scope and start URL against your app. Replace the social image placeholder in head.html with the actual absolute HTTPS image URL. These files do not certify installation or native social-platform rendering. Use Link Check to inspect what your public app actually serves.
