# Contributing

Use Node22 and pinned pnpm. Install the frozen lockfile, run pnpm check and pnpm build. Keep browser logic in strict readable TypeScript. Add focused tests for decoder, package, ownership and cancellation risks. Inspect actual exported PNGs and real keyboard/phone/desktop flows in both themes. Avoid runtime dependencies, telemetry, remote codecs and image uploads. Submit small reviewable changes with the source and checks actually performed.
